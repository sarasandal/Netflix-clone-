# Netflix Clone (Practice Project)

A front-end clone of Netflix's Homepage, built to practice HTML5 and CSS3 — layout, flexbox, and responsive design.

Not affiliated with or endorsed by Netflix. No JavaScript functionality included in this version — focus was purely on structure and styling.

## Tech Used
- HTML5
- CSS3 (Flexbox, media queries)

## Features
- Responsive layout across screen sizes
- Hover animations on movie posters
- Styled sign-up and FAQ sections

## How to Run
Open `index.html` in any browser.
